# 🎮 Snake Game

A full-stack Snake Game built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## 🚀 Features

- Real-time snake movement
- Score tracking system
- Highest score display
- Leaderboard functionality
- MongoDB database integration
- Backend API support
- Interactive game-over UI
- Dynamic food generation
- Collision detection system

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
